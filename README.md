# 表情包管理器 (emoji_container)

基于本地文件夹的表情包管理应用，支持 **Windows** 与 **Android**。

选定一个**总目录**后，其子文件夹会作为表情包集，以类似手机相册的方式浏览、整理与发送。

## 目录结构

```
总目录/
├── 零散.png           ← 根目录图片也算一个表情包集
├── 可爱猫猫/          ← 子文件夹（可含嵌套目录）
│   ├── 01.png
│   └── 子目录/02.gif
└── 沙雕表情/
    └── happy.jpg
```

- 总目录路径在应用内设置并持久保存
- 支持格式：png、jpg、jpeg、gif、webp、bmp

## 功能

- **浏览模式**：平铺（同级展示、长按拖拽排序）或嵌套（按目录层级进入）
- **封面**：九宫格或单张封面；可长按图片设为封面
- **分组**：平铺模式下可创建分组，多选后归组
- **导入**：从系统相册导入（复制 / 移动）；Android 支持从其他 App 分享图片入库
- **发送**：手机端系统分享；电脑端复制到剪贴板，并支持拖拽到聊天窗口
- **导出**：导出到系统相册，可查看与清理导出记录
- **预览**：大图缩放查看，GIF 保留动画
- **其他**：跟随系统深浅色、列表缓存加速启动、可选 `.nomedia` 减少被系统相册扫描
